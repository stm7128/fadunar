# Fadunar

**F**anza **A**nd **D**lsite **UNAR**chiver

Fadunarは、DLSiteやFanzaなどの同人音声・作品ZIPファイルを、メタデータ（作品情報）に基づいて全自動で整理・解凍する強力なデスクトップアプリケーションです。RustとTauriで構築されており、高速かつ軽量に動作します。

## ✨ 主な機能

* **🚀 ドラッグ＆ドロップで一括解凍**: 大量のZIPファイルをウィンドウに放り込むだけで、バックグラウンドで並列解凍を行います。
* **🏷️ メタデータの自動取得**: ファイル名に含まれる「RJ番号(DLSite)」や「作品ID(Fanza)」を自動認識し、公式ページから情報を取得します。
* **📁 柔軟なフォルダ命名規則**: 取得したメタデータを使って、解凍先のフォルダ名を自由にカスタマイズ可能（例: `$AUTHOR/$TITLE`）。
* **🗑️ 元ZIPの自動クリーンアップ**: 解凍が完全に成功した場合、元のZIPファイルを安全にゴミ箱へ移動します。
* **⚡ 賢いファイル除外**: `__MACOSX` や `.DS_Store` などの不要なシステムファイルを自動でスキップします。
* **🔔 デスクトップ通知**: 長時間の解凍タスクがすべて完了した際に、OSネイティブのデスクトップ通知でお知らせします。

## 📥 ダウンロード＆インストール方法

👉 **[最新版のダウンロードはこちら (Releases)](https://github.com/stm7128/fadunar/releases/latest)**

上記のページから、用途に合わせてお好きな方をダウンロードして実行してください。

*   **`fadunar_windows_x64.exe`** (おすすめ✨)
    *   インストール不要でそのまま動くポータブルアプリです。
*   **`Fadunar_x.x.x_x64-setup.exe`**
    *   PCのスタートメニューなどにしっかり登録したい人向けのインストーラーです。

## 📖 使い方

1. ダウンロードした `fadunar_windows_x64.exe` (またはインストールしたFadunar) を起動します。
2. 画面上部で「デフォルト保存先フォルダ」を設定します。
3. 同人音声や作品のZIPファイル（複数可）を、画面下部のドロップエリアにドラッグ＆ドロップします。
4. あとは全自動でメタデータを取得し、フォルダをリネームして解凍が完了するのを待つだけです！

## 👨‍💻 開発者向け (ビルド手順)

ソースコードからビルドする場合は、Node.js と Rust の開発環境が必要です。

```bash
# 依存関係のインストール
npm install

# 開発サーバーの立ち上げ
npm run tauri dev

# 本番用ビルド (.exe の生成)
npm run tauri build
```
